# imgdec

Claude Code に添付した画像（ドラッグ&ドロップ・貼り付け）を、Claude に渡る前に小さくしてトークンを節約する mod です。

画面全体のスクリーンショットなら、画像のぶんは約 3,000 トークンが約 800 トークンになります（長辺 1024px のときの推定値）。渡し方によって上乗せがあるので、下の「渡し方」を見てください。

## インストール

1. ImageMagick を入れる（macOS は無くても動きますが、余白カットが使えません）

   ```bash
   brew install imagemagick      # macOS
   sudo apt install imagemagick  # Linux
   ```

2. mod を入れる

   ```bash
   claude plugin marketplace add nakamura-shuta/claude-mod-imgdec
   claude plugin install imgdec@claude-mod-imgdec
   ```

3. Claude Code を起動し直す（起動中なら `/reload-plugins`）

private リポジトリなので、読める権限と github.com の git 認証が必要です。対応は macOS と Linux です（Windows は対象外）。

## 使い方

入れたら、あとはいつもどおり画像を添付して送るだけです。小さくしたときは、会話に結果が1行出ます。

```text
imgdec: 2000×1177 → 1024×603 (resize, ~3,096 → 814 tokens)
```

設定を変えるときは `/imgdec` を使います。設定はセッションをまたいで残ります。

| コマンド | 動き |
|---|---|
| `/imgdec` | 今の設定と、直近の結果を表示 |
| `/imgdec off` | 止める（画像をそのまま渡す） |
| `/imgdec on` | 再開する |
| `/imgdec max 1280` | 長辺の上限を変える（256〜2000px。既定は 1024） |
| `/imgdec mode resend` | 渡し方を「再送信」にする（下記） |
| `/imgdec mode read` | 渡し方を「Read」に戻す（既定） |

細かい文字が読み取られないときは、上限を上げる（1280〜1568）か、`/imgdec off` にして送り直してください。

## 渡し方

mods の API では添付画像の中身を差し替えられないので、小さくした画像は次のどれかで Claude に渡します。

| 渡し方 | 操作 | 追加のリクエスト | 使われる場面 |
|---|---|---|---|
| `@` で指定 | `@path/to/image.png` と書いて送る | なし | いつでも（モードに関係なく） |
| Read（既定） | 添付して Enter | 1回（Claude が Read を呼ぶ） | 添付・貼り付けで `mode read` のとき |
| 再送信 | 添付して Enter、入力欄に `@…` が入ったらもう一度 Enter | なし | 添付・貼り付けで `mode resend` のとき |

Read は操作が今までどおりですが、往復が1回増えます。手元の実測（2000×1333 の画像、256k の会話）では、コンテキストの増加は 3,858 → 1,720 トークンでした。長い会話では、増えた往復の費用が削減分を上回ることがあります。

再送信は Enter が2回になる代わりに、往復がありません。試作段階です。

`@` と再送信では、写しを小さい JPEG（200KB 以下）で保存します。Claude Code は、`@` で指定された画像のファイルが大きいと何も添付しないためです（手元の Claude Code 2.1.322 では、262,144 バイトまでは添付され、262,145 バイトからは添付されませんでした）。この2つは ImageMagick が必要です。

## 何をするか

1. 周囲の単色の余白を切り落とす（ImageMagick があるとき。文字の大きさは変わらない）
2. それでも長辺が上限を超えていれば縮小する
3. 小さくできた画像は、一時フォルダに保存して上の「渡し方」で Claude に渡す（元の添付は会話から外す）

- 小さくならない画像と GIF は、何もせずそのまま渡します。途中で失敗したときも同じです
- 保存先はユーザー専用の一時フォルダ（`$TMPDIR/claude-imgdec.XXXXXX/`）です。1日より古いものは、次に画像を送ったときに消します
- 画像のトークン数は縦横のピクセル数で決まるので、減らすのはピクセル数だけです（圧縮率や色数は変えません）

## 確認済みの範囲

- macOS: ドラッグ&ドロップ、クリップボードからの貼り付け、複数枚の同時添付（小さくする画像とそのまま渡す画像の混在を含む）、余白カット、縮小、`/imgdec` の各コマンド
- macOS（1枚で試しただけ）: `@` で指定した画像のすり替え、再送信
- Linux: 使うコマンド（ImageMagick 6 など）を Ubuntu 24.04 で試しただけで、Claude Code 上では未確認

## 開発

```bash
claude plugin test imgdec       # テスト
claude plugin validate imgdec   # mod として読み込めるかの検査
```

テストは、パスと本文の変換（`hooks/text.ts`）と、`@` のすり替え・`/imgdec` の各コマンド（外部コマンドを偽物に差し替えて実行）を確かめます。添付した画像を縮小する流れは、テスト環境で添付の中身を用意できないため、手で確認しています。
